# 🧾 Prompts usados durante todo el proyecto

## 🟦 1. Prompts iniciales sobre modularización
Estos fueron los primeros mensajes donde pediste ayuda para modularizar tu aplicación:

- “Modularización de código Python para separar responsabilidades.”
- “Quiero separar mi código en carpetas como src, data, services, utils, ui.”
- “Ayúdame a organizar mi proyecto en módulos.”
-“Quiero que mi proyecto sea escalable y limpio.”

## 🟩 2. Prompts sobre errores de imports
Aquí están los mensajes que usaste cuando aparecieron errores como ModuleNotFoundError:

- “Me sale error: ModuleNotFoundError: No module named 'data'.”
- “Me falla el import desde services.”
- “Ayúdame a corregir los imports.”
- “Por qué pytest no encuentra src.”
- “Me sale error: No module named 'src'.”
- “Cuando ejecuto main.py me da error de imports.”

## 🟧 3. Prompts sobre pytest y tests
Estos fueron los mensajes relacionados con la ejecución de tests:

- “pytest no encuentra los módulos.”
- “Cómo ejecutar los tests correctamente.”
- “python -m pytest funciona pero pytest no.”
- “Dame los requerimientos para que pytest funcione.”
- “Cómo ejecutar los test.”
- “Dame el requirements.txt.”

## 🟨 4. Prompts sobre estructura del proyecto
Aquí están los mensajes donde pediste ayuda para organizar carpetas:

- “Dime los errores que he tenido y coméntame los cambios.”
- “Hagamos un archivo desde donde arrancará.”
- “Ya están dentro y sigue dando error los test.”

## 🟪 5. Prompts sobre archivos auxiliares
Estos son los mensajes donde pediste archivos específicos:

- “Dame el requirements.txt.”
- “Completa el README con todo lo que hemos hecho.”

## 🟥 6. Prompts sobre ejecución del proyecto
Mensajes donde pediste ayuda para ejecutar la app:

- “Forma de ejecutar los test.”
- “Cómo ejecutar la aplicación.”

1) Modularizar el proyecto.

6) Crear pytest.ini.
7) Crear requirements.txt.
8) Completar el README.
9) Explicar los errores que tuviste.
